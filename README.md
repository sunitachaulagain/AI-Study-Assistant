# AI Study Assistant

An AI-powered study assistant for university students that uses Retrieval-Augmented Generation (RAG) to answer questions from uploaded study materials.

## Features

- User Authentication
- Subject Management
- Upload Notes (PDF, DOCX)
- AI Chat with Notes
- Quiz Generation
- Flashcard Generation
- Study Planner
- Progress Dashboard

## Tech Stack

### Frontend
- React
- Tailwind CSS

### Backend
- FastAPI

### Database
- PostgreSQL

### AI
- LangChain
- ChromaDB
- Sentence Transformers
- Google Gemini API
